# SS 33: Waqf

## What this standard is about

This standard has been replaced. AAOIFI issued a new and updated standard on waqf, SS 60 (Waqf), in March 2019. SS 60 is the standard that applies now. This file is kept only so readers looking for the old SS 33 land in the right place.

## The key point, simply put

- Do not use SS 33 as a current rulebook. Read SS 60 (Waqf) instead. It covers the same ground: what waqf is, who can create it, what property qualifies, how it is managed, and how it is supervised.
